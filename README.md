# یار هوشمند — دستیار هوش مصنوعی فارسی

یک دستیار همه‌کاره فارسی با:
- چت طبیعی فارسی
- حافظه محلی SQLite
- جست‌وجوی وب با ابزار Web Search مدل
- خواندن PDF / DOCX / XLSX / TXT
- تحلیل تصویر
- حالت‌های عمومی، پزشکی، برنامه‌نویسی، تحقیق، مالی و نویسندگی
- رابط راست‌به‌چپ و واکنش‌گرا

> این پروژه یک پایه‌ی قابل اجرا و قابل توسعه است. برای محیط واقعی باید احراز هویت، رمزنگاری، rate limit، لاگ امن، مدیریت فایل و سیاست‌های حریم خصوصی اضافه شود.

## اجرا

1. Python 3.11+ نصب کن.
2. این پوشه را باز کن.
3. `python -m venv .venv`
4. ویندوز: `.venv\Scripts\activate` / لینوکس و مک: `source .venv/bin/activate`
5. `pip install -r requirements.txt`
6. فایل `.env.example` را به `.env` تبدیل کن و `OPENAI_API_KEY` را وارد کن.
7. اجرا:
   `uvicorn app.main:app --reload`
8. مرورگر:
   `http://127.0.0.1:8000`

### نکته مدل
مدل از متغیر `OPENAI_MODEL` خوانده می‌شود؛ بنابراین اگر مدل حساب API شما متفاوت است، فقط همان متغیر را تغییر بده.

## ساختار

- `app/main.py` — API و منطق دستیار
- `app/db.py` — حافظه SQLite
- `app/prompts.py` — شخصیت و قواعد دستیار
- `static/index.html` — رابط کاربری
- `static/app.js` — منطق فرانت‌اند
- `static/styles.css` — ظاهر

## نکات پزشکی
حالت پزشکی برای آموزش و کمک به فهم اطلاعات است و جایگزین پزشک نیست. در علائم خطرناک باید کاربر را به خدمات اورژانسی/پزشک ارجاع دهد و نباید تشخیص قطعی یا نسخه‌ی شخصی‌سازی‌شده را بدون ارزیابی مناسب ارائه کند.
